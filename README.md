# Birthday Letter

Create an interactive birthday card with an envelope, letter, photo, decorations, and cake.

**Open the website:** https://zs482-cmd.github.io/birthday-letter/

To find this project on GitHub, open https://github.com/zs482-cmd/birthday-letter. The website is published with GitHub Pages from the `main` branch.

Your draft text and uploaded photos are stored in your own browser. Opening this public website on another device starts a new card; sharing a personalized card with a friend will need a separate save-and-share feature.
